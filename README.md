
# B. Beckford Law Firm – Reviews Website

A simple, responsive client review submission website for B. Beckford Law Firm.

## Project Overview

This website allows clients to share their experience with the firm by submitting a rating and written feedback.

The initial version is a frontend prototype. Google Sheets integration will be added in a future development phase.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (Hosting)
- Google Apps Script (Planned Backend)
- Google Sheets (Planned Database)

## Current Features

- Client name input
- Interactive five-star rating
- Written feedback form
- Character counter
- Required Yes/No marketing permission
- Form validation
- Responsive layout
- Submission demonstration message

## Important Notice

The current prototype does not save or transmit reviews.

Do not submit real client information until the secure backend and privacy safeguards have been implemented and tested.
